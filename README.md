# 赴日机会簿 · Japan Career Atlas

面向日语本科与 JLPT N1 求职者的公开资料求职手册，核查日期 **2026-10-29（北京时间）**，暂按 2027 届毕业整理。

- 35 条企业/岗位线索，含 2 条日本直接招聘补充。
- 含岗位、国内与日本薪资、地点、专业/语言/技术要求、赴日证据、届次、截止日期、投递或核查入口、原始出处及限制。
- 区分明确日本岗位记录、赴日研修、全球调动、研修地点待确认、未确认日本机会。
- 搜索、组合筛选、排序、收藏、投递标记、详情、筛选 CSV 导出及 HR 咨询模板。
- 零依赖静态站点，适用于 GitHub Pages 项目子路径，也能直接打开 `index.html`。

## 本地预览

在本目录执行：

```sh
python3 -m http.server 8768
```

浏览器访问 `http://localhost:8768`。本地记录仅使用浏览器 localStorage，不上传、不跨设备同步。

## GitHub Pages 部署

本项目使用 `main` 分支根目录发布，无需构建。仓库 Settings → Pages → Build and deployment → Deploy from a branch → main / (root)。`.nojekyll` 避免额外的 Jekyll 处理。

## 更新数据

`data.json` 是编辑数据源；编辑后运行以下命令统一生成网页数据、CSV 和完整研究表格：

```sh
python3 scripts/export-data.py
```

所有数据字段均为公开招聘资料的人工整理。请为新条目保留来源、核查层级与日期；未经正文确认时明确写检索摘要。不要将企业的日本总部或子公司当成外派承诺，不要把历史薪资或经验者薪资当作应届报价。

## 已知边界

这是一次公开资料快照，**不保证全国穷尽、不保证岗位仍在招、不保证录用或外派**。没有公开金额的岗位不估算。投递入口类型明确标示为岗位页、官方网申、邮件、扫码公告或检索线索；企业观察行可能没有匹配的空缺。未提交简历，未验证需要登录后的完整申请流程。

资料中未见统一排除民办本科的规则，不代表实际筛选不考虑学校。N1 不能替代商务口语、英语、编程或业务条件。筛选建议属于基于公开门槛的分析判断。
